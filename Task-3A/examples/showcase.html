4. Code Blocks¶

Python Example¶

from md2html.converter import convert_file

# Convert a Markdown file to clean HTML
output = convert_file("README.md", theme="auto")
print(f"Generated: {output}")

Bash Commands¶

# Run all unit tests
pytest -v --tb=short

# Convert a single file
python -m md2html.cli notes.md --open

# Convert a whole directory recursively
python -m md2html.cli docs/ -o build/ --recursive
