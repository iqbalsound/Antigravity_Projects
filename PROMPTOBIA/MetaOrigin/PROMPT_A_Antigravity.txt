REPORT LABELS (exact): File, MD5, SHA-256, Size, Type, Modified, Changed, Accessed, Created (only if "stat -c %W" gives a value above 0), Verify (only with --verify), Metadata (key: value lines), Evidence (lines like "[+3] text"), VERDICT ("VERDICT  : LIKELY EDITED (score 6)"), Note. Note text: "Heuristic only: metadata can be stripped or forged. The only proof a file is unchanged is a match with a trusted hash (use --verify)."

DETECTION (read magic bytes first; ZIP is OOXML if it has [Content_Types].xml, ODF if mimetype starts with application/vnd.oasis)
Score = sum of points. Verdict: score >= 3 "LIKELY EDITED"; 1-2 "POSSIBLY EDITED"; 0 and some embedded metadata found "NO EDIT INDICATORS FOUND"; 0 and no metadata "INCONCLUSIVE". Empty file: INCONCLUSIVE.
All files: +2 extension does not match the content type (jpg/jpeg, png, pdf, gif, bmp, zip/docx/xlsx/pptx/odt/ods/odp, exe, mp3, gz); +1 modified time more than 1 day in the future.
PNG (walk chunks): +3 tEXt Software names an editor (photoshop, lightroom, gimp, paint.net, pixlr, snapseed, canva, affinity, picsart, facetune, luminar, capture one, acdsee, photoscape, fotor, krita); +3 iTXt XMP (keyword XML:com.adobe.xmp) contains History, DerivedFrom or photoshop:; +1 tIME chunk present; +2 bytes after IEND. Show tEXt fields, image size and tIME as metadata.
JPEG (walk markers; read APP1 Exif little or big endian IFD0 + Exif IFD, ASCII and SHORT/LONG tags Make, Model, Software, DateTime, DateTimeOriginal, ExifWidth, ExifHeight): +3 Software names an editor; +3 XMP contains History, DerivedFrom or photoshop:; +2 DateTime differs from DateTimeOriginal by more than 2 seconds; +2 Exif dimensions differ from SOF dimensions; +1 bytes after the final FFD9. No EXIF is shown as "EXIF: absent" and adds no points.
PDF: count %%EOF; incremental updates = count - 1 (count - 2 if /Linearized appears in the first 2048 bytes); +3 if updates > 0; read /Producer /Creator /CreationDate /ModDate /Title /Author with a regex on the raw bytes; +2 ModDate more than 60 s after CreationDate; +1 Producer or Creator names an editing tool (pdf editor, pdfescape, sejda, ilovepdf, smallpdf, foxit, pdf-xchange, nitro, pdfelement, pdffiller, pikepdf, pypdf, pdftk, itext, acrobat).
OOXML (docx, xlsx, pptx): read docProps/core.xml (creator, lastModifiedBy, created, modified, revision) and docProps/app.xml (Application, AppVersion, TotalTime): +2 revision > 1; +2 modified more than 60 s after created; +2 lastModifiedBy differs from creator (both non-empty); +1 TotalTime > 0; +3 word/document.xml contains "<w:ins " or "<w:del "; +1 a comments.xml part exists.
ODF (odt, ods, odp): meta.xml: +2 editing-cycles > 1; +2 date more than 60 s after creation-date; +2 creator differs from initial-creator.
Other types: only the generic checks. Parsing errors never crash: show "Parse note: partial".
